Causal BlocksGame ideas

Every version of the game

Each idea is kept playable, so we can compare them and go back to any of them.

  1. 1
    Hilltop SchoolThe first full prototype: newspaper headlines, a detective, six levels with the whole cast. Also saved as the git tag prototype-v1.
  2. 2
    EvidenceEvidence cards, no article. Draw a theory that fits every card. Blocks you get wrong complain.
  3. 3
    TestA secret graph. Tap a block to run a test and see what really changes. Some blocks are 🔒 locked: only the data can tell you about them.
  4. 4
    ParLike Test, scored like golf: par is the fewest arrows that explain everything.
  5. 5
    Rapid fireHeadlines against the clock: A causes B, B causes A, or something else causes both?
  6. 6
    CastAlmost no words. Each level has a twist: Mr Confounder sneaks on, the Messenger gets frozen, the Bouncer shuts the door.
  7. 7
    CrowdA crowd in a four-corner grid shows a link. Draw arrows to explain it, then watch the crowd split into piles.
  8. 8
    Hot day, cold dayIce cream and shark attacks. Two beaches side by side, one hot, one cold. Close the stand, close the sea, and draw what really causes what.
